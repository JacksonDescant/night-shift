# Security policy

Night Shift handles repository tokens and can merge code, so we take reports seriously.

**Please don't open a public issue for a vulnerability.** Report it privately through GitHub's
"Report a vulnerability" button on this repository's Security tab. Include what you found, how to
reproduce it, and its impact. You'll get a reply within a few days.

In scope: token handling, the dashboard's access controls, the mimic's isolation, the autonomy
gate (anything that lets an unproven or sensitive change merge without a human), and webhook
verification.
